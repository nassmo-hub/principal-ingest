Privacy Policy

PRINCIPAL Ingest · last updated 14 September 2026

Scope of this application

PRINCIPAL Ingest is a private utility operated by one individual. It has no public users, no sign-up, and provides no service to anyone other than its operator. It accesses exactly one Google account — an account created by and belonging to the operator for this purpose.

What data is accessed

The application requests a single Google OAuth scope: https://www.googleapis.com/auth/gmail.readonly. This permits reading messages and settings in the connected mailbox. It does not permit sending, modifying, or deleting messages, and the application does none of those things.

How that data is used

Message content is read so it can be summarized and organized into the operator's own private working notes. The data is used only for the operator's own reference in the ordinary course of their work.

How that data is stored

Extracted information is stored in a private repository controlled by the operator. Access credentials are held as environment variables and are not stored in that repository or in any public location.

What is not done with the data

  • It is not sold, rented, or licensed to anyone.
  • It is not transferred to any third party, except as required by law.
  • It is not used for advertising, profiling, or marketing of any kind.
  • It is not used to train any machine learning or AI model.
  • It is not made available to any other person, because there are no other users.

Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Access can be revoked at any time by the operator from the Google Account security settings, which immediately ends the application's ability to read the mailbox. Stored extracts can be deleted by the operator at any time.

Contact

Questions about this policy can be directed to principalgmail3@gmail.com.
